# 小熊模拟器 · Android 端

在 Android 上运行安卓实例的模拟器。本仓库是**小熊模拟器**项目的 Android 端实现。

共享规格层：[xiaoxiong-emulator-spec](https://github.com/MissKisser/xiaoxiong-emulator-spec)（以 submodule 引入至 `spec/`）

## 技术路线

采用**系统级容器**。在安卓框架层重定向系统服务，让容器内的安卓应用看到一套完整的系统环境；宿主上并不存在传统的虚拟机或虚拟设备节点。

这是**结构性**路线：痕迹不是被隐藏起来，而是从未产生，因此应用无从检测。这一点与 Windows 端的对抗性隐藏路线有本质区别，也是两端不共享隐藏栈实现的原因。

## 目标能力

| 能力 | 要求 |
|---|---|
| 应用可运行 | 容器内可安装并正常运行常规安卓应用 |
| 数据隔离 | 每个实例的数据独立，不可跨实例读取 |
| 身份隔离 | 设备标识由宿主注入，跨实例不重复 |
| 无虚拟化痕迹 | 容器内不出现虚拟机或 root 框架的相关特征 |
| 无需 root | 宿主无需 root 权限即可使用 |

## 技术栈

- **Kotlin + Jetpack Compose** —— 应用层
- **Rust** —— 原生层容器运行时（参考开源项目 `twoyi` 的 `libtwoyi.so` 形态）
